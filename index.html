ARTICLE 01 · PYTHON

Pythonで設備状態CSVを集計し、稼働率を計算する

設備や実験装置の状態ログは、「いつ、どの状態になったか」という時刻と状態の組で保存できます。これを利用すると、各状態が継続した時間を集計する簡単なダッシュボードを作れます。

1. 入力データの形式を決める

CSVには timestamp と status の2列を用意します。日時をタイムゾーン付きISO 8601形式で統一すると、時差による誤解を減らせます。

timestamp,status
2026-10-15T09:00:00+09:00,RUNNING
2026-10-15T09:30:00+09:00,STOPPED
2026-10-15T10:00:00+09:00,UNKNOWN

この例は説明用の架空データです。各行の状態は次の行の時刻まで続いたと仮定します。最後の行については、観測終了時刻を別途指定する必要があります。

2. 状態ごとの時間を求める

先頭のRUNNINGは9時00分から9時30分までの30分、STOPPEDは9時30分から10時00分までの30分です。Python標準ライブラリの datetime で日時を読み取り、隣接する行の差を計算できます。

from datetime import datetime

start = datetime.fromisoformat("2026-10-15T09:00:00+09:00")
end = datetime.fromisoformat("2026-10-15T09:30:00+09:00")
minutes = (end - start).total_seconds() / 60
print(minutes)  # 30.0

3. 稼働率の定義に注意する

状態が分かっている時間を分母とする簡易稼働率は、以下のとおりです。

稼働率［%］= RUNNING時間 ÷（RUNNING時間 + STOPPED時間）× 100

たとえば稼働30分・停止30分であれば50%です。不明時間を除外すると値が高く見える場合があります。UNKNOWNを別に示し、実際の観測範囲も表示してください。これはOEE（設備総合効率）ではなく、性能ロスや不良率を評価しません。

4. 入力チェックと安全な運用

  • 時刻の昇順と重複の有無をチェックする
  • 空のCSV・不正な状態値・タイムゾーン欠落を検出する
  • 記録漏れや通信断は、取得できない情報として明示する
  • 生成レポートを設備の自動停止や安全判断に用いない

これらのルールを実装したCSV→HTMLレポート生成ツールは、ローカルのサンプルデータを使用した単体テスト6項目で成功を確認しています。実設備との直接接続は未検証であり、PLCの制御機能もありません。

ARTICLE 02 · RASPBERRY PI

Raspberry Pi Picoシリーズで電子工作を始める前に

Raspberry Pi Picoシリーズは、センサの読み取りやLEDの点灯などを行うマイコンボードです。一般的なRaspberry Piと異なり、デスクトップOSを使うパソコンの代用品ではありません。

1. 目的に応じた開発環境

MicroPythonまたはC/C++などから目的に合う開発言語を選び、公式ドキュメントに従って開発環境を導入します。最初は機器の認識、サンプルの実行、シリアル出力の確認という順で進めると問題を切り分けやすくなります。

2. GPIOに接続する前に確認する

  • 使うPicoのモデル名と正しいピン配置を調べる
  • GPIOの定格電圧・電流をデータシートで確認する
  • モータやリレーなどの負荷は、対応するドライバ回路を介して動かす
  • 配線変更前に電源を切り、極性・GND共通化を再確認する

3. 動作記録を残す

実験した日付、配線図、コードの版、電源条件、観察結果をまとめておくと再現性が高まります。本記事は一般的な導入ガイドであり、特定の回路を実機で検証したものではありません。

ARTICLE 03 · ELECTRONICS

電子工作の工具・測定器を選ぶときの考え方

工具を購入するときは、単純なランキングよりも作業対象に適合するかを重視します。ドライバー・ニッパー・ピンセット・テスターなども、対象の材質やサイズで使いやすさが変わります。

選ぶときに確認したい項目

  • 対応寸法、適合するネジ頭、切断可能な材料・太さ
  • 消耗品や交換部品の入手しやすさ、製品保証
  • 測定器なら測定範囲、確度、定格や測定カテゴリ
  • 絶縁工具は、必要な規格・用途に適合すること

電気安全： 家庭の交流電源や高電圧回路を扱う作業には感電・火災の危険があります。資格や法令、製品の安全表示を必ず確認してください。低電圧の実験でも誤配線や短絡には注意が必要です。
